Example Usage Scenarios

Scenario A: A Parent Limiting a Child’s Game

Goal: Child may only play a certain game on weekends.

  1. Open ProgramBlocker.
  2. Click Select .EXE, choose the child’s game file (e.g. game.exe).
  3. In the Block Options window:
    • Choose Block Execution.
    • Check Protect this block with a password, enter a password only the parent knows.
    • Check Enable scheduling for this block.
    • Set Start: today 00:00, End: today 23:59.
    • Check days: Sun, Mon, Tue, Wed, Thu, Fri (Monday-Friday + Sunday).
    • Don’t check Sat (Saturday is free).
  4. Click OK.

Result: The game can only be opened on Saturday. On other days, the game is blocked.

Scenario B: An Employee Focusing Away from Social Media

Goal: Block WhatsApp and social media during work hours.

  1. Open ProgramBlocker.
  2. Add WhatsApp.exe, Discord.exe, and Telegram.exe to the list.
  3. In Block Options:
    • Choose Block Internet.
    • Check Enable scheduling for this block.
    • Set Start: 09:00, End: 17:00.
    • Check days: Monday-Friday.
  4. Click OK.

Result: During work hours, all three apps can’t access the internet. Outside work hours, internet works normally.
