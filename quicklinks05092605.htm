Scheduling Automatic Blocks (Schedule)

You can schedule a block to automatically activate at a certain time and automatically deactivate afterward. This feature is very useful for:

  • Limiting game play time (e.g. only openable on weekends).
  • Blocking internet during work hours.
  • Automatically unblocking during break time.

How to Create a Schedule

  1. When the Block Options window opens to block a program, find the Schedule section.
  2. Check the box Enable scheduling for this block.
  3. Set the Start date/time (when the block activates).
  4. Set the End date/time (when the block ends).
  5. (Optional) Check the days you want to repeat: Sun, Mon, Tue, Wed, Thu, Fri, Sat.
    • If no days are checked, the schedule applies only once.
    • If any days are checked, the schedule repeats every week on those days.
  6. Click OK.

Viewing the Schedule List

  1. Choose menu File → Schedules…, OR right-click the tray icon in the corner of the screen and choose Schedules….
  2. The Schedules window will open, showing all schedules you’ve created.
  3. You can see columns: Program, Block Type, Start, End, Repeat Days, Enabled, Status.
  4. Available buttons:
    • Delete — Delete the selected schedule (with confirmation).
    • Enable/Disable — Activate or deactivate a schedule without deleting it.
    • Refresh — Reload the list.
    • Close — Close the window.

Important Notes About Schedules

  • Schedules keep running even when the main software is closed.
  • The service checks schedules every 30 seconds.
  • If the schedule is currently active (status "Active"), the block is being applied.
  • If the schedule hasn’t started yet (status "Waiting"), the block isn’t active yet.
  • If the schedule has already passed (status "Expired"), the block has already been removed.
