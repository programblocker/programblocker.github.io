Frequently Asked Questions (FAQ)

Q1: Is ProgramBlocker free?

A: ProgramBlocker is available in two versions:

  • Trial (free) — Can be used without paying, with limitations: 10 Block uses, and no anti-rename protection.
  • Pro (paid) — After purchasing a serial key, all limitations are removed. One-time payment, no subscription.

Q2: Does ProgramBlocker need internet to work?

A: No. ProgramBlocker works fully offline. Even Pro activation is done offline — no server is contacted.

Q3: Does ProgramBlocker slow down the computer?

A: No. The software is very lightweight. The background service uses only a small amount of CPU and memory (usually under 20 MB RAM). You won’t notice any performance difference.

Q4: Can ordinary users bypass the Trial block?

A: Unfortunately yes, with the trick of renaming the file of the program. That’s why there’s a Pro version that applies full layered blocking. For hard-to-bypass protection, upgrading to Pro is recommended.

Q5: Do blocks stay active after the computer is restarted?

A: Yes, as long as the background service is installed (which happens automatically the first time you run ProgramBlocker). Even if the main software isn’t running, the service will maintain the blocks.

Q6: Can a Trial user block more than 10 programs?

A: No. The 10-use limit only applies to the Block Internet and Block Execution feature.
