How to Block a Program from Running

Blocking execution prevents a program from being run at all. Even if you or someone else double-clicks the program file, the program won’t open.

Steps

  1. Select a program in the list by clicking its row.
  2. Click the Actions button in the toolbar, then choose Block Execution, OR choose menu Actions → Block Execution.
  3. The Block Options window will appear.
  4. Choose Block Execution as the block type.
  5. (Optional) Configure password and schedule as needed.
  6. Click OK.
  7. A confirmation message will appear: Block ENABLED for: [file name] / Type: Execution.
  8. In the program list, the Execution column will change to "BLOCKED" (in red).
