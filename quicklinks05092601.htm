How to Block a Program’s Internet Access

Blocking internet access prevents a program from sending or receiving data over the internet. The program can still be run, but all features that require internet will fail.

Steps

  1. Select a program in the list by clicking its row.
  2. Click the Actions button in the toolbar, then choose Block Internet, OR choose menu Actions → Block Internet.
  3. The Block Options window will appear (see details below).
  4. Choose Block Internet as the block type.
  5. (Optional) Check Protect this block with a password and enter a password to protect the block.
  6. (Optional) Check Enable scheduling for this block if you want to schedule it.
  7. Click OK.
  8. A confirmation message will appear: Block ENABLED for: [file name] / Type: Internet.
  9. In the program list, the Internet column will change to "BLOCKED" (in red).
