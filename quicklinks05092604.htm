Protecting a Block with a Password

You can protect each block with a password, so others can’t remove the block without your knowledge.

How to Set a Password on a Block

  1. When the Block Options window opens (when blocking a program), find the Protection Password section.
  2. Check the box Protect this block with a password.
  3. Enter the password in the Password box.
  4. Enter the same password in the Confirm box.
  5. (Optional) Check the eye-icon box to show the password as you type.
  6. Click OK.

Password tip: Use a password that’s easy for you to remember but hard for others to guess. Combine uppercase letters, lowercase letters, numbers, and symbols. Avoid using birthdates or family member names.
